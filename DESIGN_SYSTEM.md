# Design System Summary

## Simplified Color Palette
**Primary Colors:**
- White backgrounds (`bg-white`)
- Black text (`text-brand-black`)
- Lavender accent (`brand-lavender`) - used sparingly for highlights

**Usage:**
- Main backgrounds: White
- Text: Black with opacity variations (60%, 70% for secondary text)
- Accents: Lavender for hover states, active links, CTAs
- Cards: Subtle black/5 backgrounds with black/10 borders

## Consistent Page Structure
All pages follow this pattern:
1. **Navbar**: Fixed, z-[100], white on scroll
2. **Hero Section**: White background, large serif headings
3. **Content Sections**: White backgrounds, clean spacing
4. **Footer**: Consistent across all pages

## Typography
- Headings: `font-serif` (large, 5xl-7xl)
- Body: Default sans-serif
- Labels: Uppercase, tracking-widest, small

This creates a clean, professional, minimal aesthetic focused on content and readability.
