# Tarot Card Images Guide (Descriptive Filenames)

## Directory Structure
Place images in `public/tarot-cards/` organized by type:

```
public/
└── tarot-cards/
    ├── major/          (22 images)
    └── minor/
        ├── wands/      (14 images)
        ├── cups/       (14 images)
        ├── swords/     (14 images)
        └── pentacles/  (14 images)
```
