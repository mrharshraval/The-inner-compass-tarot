## Tips for Using These Prompts

1. **Consistency**: Use the same prompt structure for all cards to maintain visual coherence
2. **Batch Generation**: Generate 5-10 cards at a time to avoid fatigue
3. **Review**: Check each card matches the traditional meaning
4. **Adjust**: If a card doesn't look right, add more specific details to the prompt
5. **Save Properly**: Name files exactly as specified in TAROT_IMAGES_GUIDE.md
6. **Upscale**: Use DALL-E's upscale feature or external tools for higher resolution
